# Smart Calendar

A simple, responsive, and feature-rich calendar application built with HTML, CSS, and JavaScript.

## Features

- Displays a calendar with the current date highlighted.

*   **Responsive Design:**
 Adapts to different screen sizes for optimal viewing on desktops, tablets, and mobile devices.

*   **Theme Toggle:** 
Allows users to switch between light and dark themes for comfortable viewing in various lighting conditions.

*   **Event Management:**
    *   Add events to specific dates.
    *   Categorize events as Work, Personal, or School.
    *   Mark events as urgent.
    
*   **Intuitive Navigation:** Easily navigate through months and years using dedicated buttons.

*   **Clear Display:** Highlights the current date and indicates days with events.

## Technologies Used

*   HTML
*   CSS
*   JavaScript
